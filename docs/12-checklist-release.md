# Чек-лист перед публикацией

Проходите сверху вниз. Если пункт нельзя отметить — не публикуйте: исправление после релиза
дороже, а часть ошибок в Play уже не исправить (applicationId, подпись).

## A. Код и сборка

- [ ] `app.applicationId` задан окончательно (например, `com.blockpuzzle.app`).
- [ ] `app.versionCode=1`, `app.versionName=1.0.0`.
- [ ] `ads.testMode=false` и все пять блоков — реальные ID из РСЯ.
- [ ] `Config.PRIVACY_POLICY_URL`, `PLAY_MARKET_URL`, `SUPPORT_EMAIL` заполнены и открываются.
- [ ] `./gradlew testDebugUnitTest` — зелёные (логика игры + частотная политика рекламы).
- [ ] `./gradlew bundleRelease` собирается без ошибок, lint не падает на устаревшем SDK.
- [ ] `keystore.properties` создан, пароль сохранён в менеджере паролей, ключ забэкаплен.
- [ ] В `.gitignore` нет ваших паролей и keystore (проверьте `git status` — файлы не в коммите).

## B. Реклама: правила и UX (ручная проверка на устройстве)

- [ ] Диалог согласия показывается при первом запуске, до любого запроса рекламы.
- [ ] Баннер: не перекрывает кнопки, ничего не «прыгает» при его появлении,
      элементы игры не ближе ~8 dp к границе баннера.
- [ ] Баннер не показывается на игровом экране во время партии.
- [ ] Interstitial: только после проигрыша и нажатия «Играть снова», не чаще 1 раза в 60 секунд
      и не чаще каждого 2-го проигрыша.
- [ ] Interstitial не показывается на первом запуске и сразу после App Open.
- [ ] Rewarded: показывается только по нажатию кнопки, награда приходит после `onRewarded`,
      досрочное закрытие награду не даёт; после показа следующее объявление предзагружается.
- [ ] App Open: не чаще 1 раза в 4 часа, не поверх игрового процесса, не сразу после другого
      полноэкранного формата.
- [ ] Нигде нет стимулов «нажми на рекламу» и своих элементов поверх креатива.
- [ ] Ни один рекламный блок нельзя случайно нажать во время игры.
- [ ] Кнопки и текст не накладываются на системные панели (edge-to-edge, `navigationBarsPadding`).
- [ ] Ориентация зафиксирована, игра не «перезапускается» при повороте.

## C. Приложение: качество

- [ ] Обучение проходится за < 60 секунд и понятно без текста.
- [ ] Игра не крашится и не зависает: 20 партий подряд, свёртывание/разворот, звонок,
      блокировка экрана, включение авиарежима.
- [ ] Прогресс сохраняется (рекорд, монеты, темы, достижения) после перезапуска.
- [ ] Ежедневный бонус выдаётся один раз в сутки.
- [ ] «Продолжить» и «×2 монеты» доступны один раз за партию.
- [ ] Игра корректно работает без сети (реклама просто не показывается, игра играется).
- [ ] Нет ANR и утечек: баннер и загрузчики освобождаются при выходе с экрана.
- [ ] Тексты без опечаток на ru и en (проверьте оба языка, сменив язык системы).

## D. Google Play: страница и формы

- [ ] Иконка 512×512, feature graphic 1024×500, 4–8 скриншотов (`store-listing/`, пересборка — `store-listing/make-screenshots.py`).
- [ ] Короткое (≤ 80) и полное (≤ 4000) описание — из `store-listing/`.
- [ ] Privacy policy URL указан.
- [ ] Data safety заполнена (рекламный ID — да, локальные данные — нет).
- [ ] «Содержит рекламу» — Да.
- [ ] Content rating пройден.
- [ ] Target audience: 13+, не «дети».
- [ ] Скриншоты и описание соответствуют реальной игре.
- [ ] Closed testing: 12 тестировщиков, 14 дней (требование для новых личных аккаунтов).

## E. РСЯ и сайт

- [ ] Аккаунт РСЯ: оферта принята, платёжные данные заполнены.
- [ ] Приложение добавлено, доступ подтверждён (app-ads.txt или контакты в магазине).
- [ ] Блоки созданы и названы понятно; ID скопированы в `gradle.properties`.
- [ ] Сайт разработчика указан в Google Play.
- [ ] `privacy-policy.html` и `app-ads.txt` открываются в браузере без авторизации.
- [ ] `app-ads.txt` содержит ID партнёра из интерфейса РСЯ (статус — без ошибок).
- [ ] Прямые ссылки на политику конфиденциальности нет в описании магазина только «от разработчика» —
      продублируйте её в App content.
