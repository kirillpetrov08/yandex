# Баннер (адаптивный sticky и inline)

## Что это

Баннер — блок, в котором могут показываться комбинаторные объявления, медийная реклама и видео.
Размер блока задаёт приложение, а количество объявлений и размер шрифта SDK подбирает сам.

Два адаптивных вида (оба требуют ширину в dp):

| Вид | Создание | Высота | Где применять |
| --- | --- | --- | --- |
| **sticky** | `BannerAdSize.sticky(context, widthDp)` | автоматически, **не более 15% высоты экрана**, автообновление | внизу или вверху экрана: меню, магазин, настройки |
| **inline** | `BannerAdSize.inline(context, widthDp, maxHeightDp)` | подбирается автоматически, вплоть до высоты экрана | ленты, списки, экран результатов |

Старый `fixedSize()` оставлен только для обратной совместимости — использовать не рекомендуется.
Минимальный размер, в котором поддерживается **видео**: 300×60 или 160×300 dp.

**Важно:** с версии 6.0.0 sticky-баннер обновляется сам. Собственный таймер автообновления нужно
убрать, иначе получите двойные запросы и снижение дохода.

## Интеграция (SDK 8.x)

```kotlin
val bannerAdView = BannerAdView(context).apply {
    setAdSize(BannerAdSize.sticky(context, containerWidthDp))
    setBannerAdEventListener(object : BannerAdEventListener {
        override fun onAdLoaded() { /* баннер готов */ }
        override fun onAdFailedToLoad(error: AdRequestError) {
            // Повторную загрузку из этого колбэка инициировать не рекомендуется
        }
        override fun onAdClicked() {}
        override fun onImpression(data: ImpressionData?) {}
    })
}
bannerAdView.loadAd(AdRequest.Builder(adUnitId).build())
```

Ключевые моменты, которые чаще всего ломают интеграцию:

1. **Ширину берите у контейнера, а не у экрана**: `containerView.width` в пикселях → разделить на
   `displayMetrics.density` → округлить. Иначе на устройствах с вырезом/отступами баннер будет «резаться».
2. **Ширину можно получить только после разметки**: подпишитесь на `ViewTreeObserver.OnGlobalLayoutListener`
   (или `onGloballyPositioned` в Compose) и удалите слушатель после первого вызова.
3. **Высота известна до запроса** (`bannerAdSize.getHeightInPixels(context)`) — зарезервируйте её в разметке,
   чтобы контент не «прыгал» при появлении баннера. Скачки контента = случайные клики = нарушение правил РСЯ.
4. **Вызывайте `destroy()`**, когда экран уничтожается, иначе баннер (и его таймер) живёт вечно и течёт память.
5. Если в `onAdLoaded()` Activity уже уничтожена — вызывайте `destroy()` и выходите.
6. SDK должен быть инициализирован **до** создания `BannerAdSize`.

## Как это сделано в нашей игре

`app/src/main/java/com/blockpuzzle/app/ads/BannerSlot.kt` — Compose-обёртка `YandexBannerSlot`:

- ждёт инициализации SDK (`Ads.initialized`);
- измеряет ширину контейнера через `onGloballyPositioned`;
- создаёт `BannerAdView` внутри `AndroidView`, задаёт sticky-размер и грузит объявление;
- резервирует высоту баннера в разметке (контент не сдвигается);
- вызывает `destroy()` в `DisposableEffect`.

Подключение на экране — одна строка (уже встроено в `ScreenScaffold`):

```kotlin
YandexBannerSlot(modifier = Modifier.fillMaxWidth().navigationBarsPadding())
```

Во время партии баннер **не показывается**: игровое поле должно занимать максимум места,
а тапы рядом с рекламой легко приводят к случайным кликам.

## Правила размещения баннеров

- Баннер не должен перекрывать контент приложения и элементы управления.
- Нельзя размещать кликабельные элементы приложения вплотную к баннеру (риск случайного клика).
- Нельзя «маскировать» рекламу под элемент игры, добавлять свои рамки/подписи поверх креатива.
- Нельзя стимулировать клики («нажми на баннер и получи монеты») — это прямое нарушение.
- Нельзя влиять на показы программно (эмуляторы кликов, автотесты на реальном блоке).
- Не показывайте баннер на экране, где пользователь только что получил награду и ждёт действия —
  он ждёт кнопку, а попадает по рекламе.

## Проверка

```bash
# Диагностика SDK в логе (в том числе для баннера)
adb logcat -v brief '*:S YandexAds'
# В логе должно быть: "Ad type banner was integrated successfully"
```

Если баннер пустой:
1. Проверьте, что `ads.testMode=true` даёт демо-объявление (`demo-banner-yandex`).
2. Проверьте гео: в некоторых регионах нет заполнения.
3. Смотрите `onAdFailedToLoad`: `code` и `description` в логе — самый быстрый путь к причине.
