# Реклама с вознаграждением (Rewarded)

## Что это

Полноэкранный формат, за просмотр которого пользователь получает награду: внутриигровую валюту,
жизнь, подсказку, удвоение награды. Это **самый доходный формат в бесплатных играх**:
пользователь мотивирован, смотрит ролик целиком и сам инициирует показ.

Требования к длительности просмотра:

- **комбинаторная реклама** — 30 секунд;
- **видеореклама** — до конца ролика.

В интерфейсе РСЯ при создании блока вы указываете **название валюты** и **сумму вознаграждения
за первый полный просмотр** — эти данные нужны сети для аналитики, а саму награду выдаёте вы в коде.

## Интеграция (SDK 8.x)

```kotlin
val loader = RewardedAdLoader(context)
loader.loadAd(
    AdRequest.Builder(adUnitId).build(),
    object : RewardedAdLoadListener {
        override fun onAdLoaded(rewardedAd: RewardedAd) { ad = rewardedAd }
        override fun onAdFailedToLoad(error: AdRequestError) { /* backoff, не цикл */ }
    },
)

ad?.setAdEventListener(object : RewardedAdEventListener {
    override fun onAdShown() {}
    override fun onAdFailedToShow(adError: AdError) { /* вернуть интерфейс в исходное состояние */ }
    override fun onAdDismissed() { /* очистить и предзагрузить следующее */ }
    override fun onRewarded(reward: Reward) {
        // ВОТ ЗДЕСЬ выдаём награду: reward.amount, reward.type
    }
    override fun onAdClicked() {}
    override fun onAdImpression(data: ImpressionData?) {}
})
ad?.show(activity)
```

**Главное правило:** награда выдаётся в `onRewarded()`, а не в `onAdDismissed()`.
Если пользователь закрыл ролик раньше времени, `onRewarded` не вызовется — так сеть гарантирует,
что оплаченный и неоплаченный просмотр различимы.

## Точки вознаграждения в нашей игре

| Точка | Награда | Когда доступна | Логика |
| --- | --- | --- | --- |
| «Продолжить» | очищаются 2 нижних ряда, партия продолжается | в окне проигрыша, 1 раз за партию | самый сильный крючок: игрок в шаге от личного рекорда |
| «×2 монеты» | удвоение монет за партию | в окне проигрыша, 1 раз за партию | превращает «ещё одну партию» в просмотр |
| «Бесплатные монеты» | +50 монет | магазин, без ограничений | монетизирует прогресс-мотивацию (темы) |
| Ежедневный бонус | +25 монет | раз в сутки | **без рекламы** — специально: ретеншн важнее одного показа |

Кнопки наградного действия визуально отличаются (зелёные, с подписью «Смотреть рекламу»)
и **всегда отключены, пока объявление не загружено** — если ролика нет, мы честно показываем
«Реклама сейчас недоступна» и не выдаём награду. Это требование честности к пользователю
и защита от жалоб модерации.

## Правила и подводные камни

1. **Никогда не выдавайте награду без просмотра.** Любая имитация просмотра — нарушение.
2. **Никогда не показывайте rewarded автоматически** (например, «между уровнями») — только по действию пользователя.
3. Кнопка должна быть явной: пользователь понимает, что получит и за что.
4. Если рекламы нет — не наказывайте пользователя: дайте альтернативу или сообщите, что бонус временно недоступен.
5. После показа сразу **предзагружайте следующее объявление** — иначе в следующий раз кнопка будет пустой.
6. Не ставьте два rewarded-действия в один диалог «цепочкой» — пользователь устанет и закроет игру.
