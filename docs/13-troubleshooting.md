# Диагностика: реклама не показывается и другие проблемы

## 0. Включите логи SDK

```kotlin
YandexAds.enableLogging(true) // только debug-сборка!
```

```bash
adb logcat -v brief '*:S YandexAds'
adb logcat -v brief '*:S YandexAds' | grep -i "integration\|banner\|interstitial\|rewarded"
```

Что должно появиться при корректной интеграции:

```
Yandex Mobile Ads 8.6.0 integrated successfully
[Integration] Ad type banner was integrated successfully
[Integration] Ad type interstitial was integrated successfully
```

Плюс в настройках профиля РСЯ включите показ тестовых объявлений, чтобы проверять без реального трафика.

## 1. Ничего не загружается (все форматы пустые)

| Причина | Признак | Решение |
| --- | --- | --- |
| SDK не инициализирован | в логе нет строк инициализации | грузите рекламу из колбэка `initialize` |
| Неверный ID блока | `onAdFailedToLoad` с ошибкой формата | скопируйте ID из РСЯ ещё раз |
| Блок не того формата | баннер просит `demo-...` и т.п. | используйте ID, соответствующий формату |
| Нет сети | лог `network` | включите интернет; проверьте `ACCESS_NETWORK_STATE` |
| Приложение не одобрено | в РСЯ статус «на модерации»/«отклонено» | до одобрения доступны только демо-блоки |
| `ads.testMode=true` и демо-ID, но пусто | истёк тестовый режим | замените на реальные ID |
| Приложение на модерации Google Play, но РСЯ ещё нет | «NO FILL» в логах | добавьте приложение в РСЯ и пройдите модерацию |

## 2. Баннер

- **Пустая полоса** — обычно пришёл `NO FILL` (нет подходящего объявления для этой ширины/гео).
  Проверьте ширину: баннер должен быть не уже 300 px по ширине экрана.
- **Баннер обрезан** — размер задан от ширины экрана, а не от контейнера. Считайте ширину
  от родительского вью:
  `widthPx / context.resources.displayMetrics.density`.
- **Баннер появляется и «прыгает» контент** — резервируйте высоту до загрузки
  (`BannerAdSize.getHeightInPixels`); это ещё и требование модерации.
- **Баннер не исчезает при уходе с экрана** — забыт `destroy()`.
- **Двойные запросы** — свой таймер автообновления. Уберите: SDK обновляет сам.

## 3. Interstitial

- **Показ не происходит** — объект `InterstitialAd` собрал GC: держите strong reference до показа.
- **`onAdFailedToShow`** — объявление устарело (долго лежало). Загружайте непосредственно перед
  предполагаемым показом или сразу перезагружайте после `onAdDismissed`.
- **Не показывается второй раз после `onAdDismissed`** — не сбросили ссылку и не перезагрузили.
- **Бесконечные запросы** — вы вызываете `loadAd` из `onAdFailedToLoad`. Используйте backoff.
- **Падение «Only main thread»** — вызов не из главного потока.

## 4. Rewarded

- **Награда не выдаётся** — вы слушаете `onAdDismissed` вместо `onRewarded`
  (последний вызывается только за полный просмотр).
- **Кнопка «мертвая»** — объявление не загружено/не предзагружено после предыдущего показа.
  Всегда грузите следующее сразу после закрытия.
- **Один и тот же ролик** — тестовый режим/демо-блок; в релизе для отладки оставьте
  показ тестовых объявлений в настройках профиля РСЯ.

## 5. App Open

- **Показывается слишком часто** — нет частотного ограничения; у нас `ads.appOpenIntervalHours=4`
  и `AdPolicy.canShowAppOpen()`.
- **Показывается на каждом экране** — вы подписались на `onResume` Activity вместо
  `ProcessLifecycleOwner` (нужен только `onStart` процесса).
- **Показ после выхода из другого полноэкранного формата** — используйте `suppressFor(ms)`.
- **Черный экран** — `show()` вызван для уничтоженной Activity. Проверяйте `isFinishing/isDestroyed`.

## 6. Нативная реклама

- **Пустой белый блок** — не пришёл `AdBindingResult.Success`. Обязательные вью:
  `sponsored`, `feedback`, `title`, `body`, `domain`, `icon`, `media`, `callToAction`, `age`.
  Любой `null`/пустой → `Failure`. Мы в этом случае скрываем блок целиком — так и надо.
- **Кликается всё подряд** — блок обёрнут в кликабельный контейнер. Кликабельны только вью,
  переданные в билдер.
- **Блок мерцает/перезагружается** — чаще одного раза в 30 секунд обновлять нельзя.
- **Нарушение вёрстки** — заголовок обрезается, изображение увеличено (можно только уменьшать),
  предупреждения занимают меньше 10% площади.

## 7. Ошибка «SDK version is outdated»

Линт-проверка `YandexAdsSdkOutdatedVersion` валит релизную сборку.
Обновите зависимость `com.yandex.android:mobileads` до актуальной в
<https://github.com/yandexmobile/yandex-ads-sdk-android/blob/main/CHANGELOG.md> (или временно
отключите проверку через `lint { disable += "YandexAdsSdkOutdatedVersion" }` — но лучше обновить).

## 8. Чек-лист «реклама не грузится — что проверить по порядку»

1. `adb logcat -v brief '*:S YandexAds'` — что говорит сам SDK.
2. В РСЯ: приложение Active? блок Active? формат/гео совпадают? есть ли статистика запросов?
3. ID блока в `gradle.properties` совпадает с интерфейсом РСЯ (посимвольно).
4. Приложение = `com.blockpuzzle.app` в РСЯ, совпадает со сборкой.
5. Сеть доступна; тестовые объявления в профиле включены.
6. Сборка пересоздана после правки `gradle.properties` (BuildConfig подставляется при компиляции).

## 9. Мониторинг в продакшене

- **РСЯ** → отчёты: показы, клики, CTR, eCPM по каждому блоку и гео.
- **Google Play Console** → Android vitals: crash-free, ANR; отзывы.
- **AppMetrica** (если подключите) → воронка «проигрыш → кнопка rewarded → просмотр → новая партия».
- Алерты: падение fill rate и роста ошибок `NO FILL` обычно означает проблемы с модерацией
  или с конфигом блока — проверьте статус приложения в РСЯ.
