# Release notes (What's new)

Play Console → Release → Notes. Лимит: **500 символов** на язык. Ниже версия 1.0.0 — стартовая.

• Classic 8x8 board with three blocks in the tray

## Заготовки для следующих версий (меняйте перед публикацией)

Обновление 1.1.0 (пример):

```
Что нового

• Улучшили работу рекламы: показы стали стабильнее, игра не ждёт загрузки видео.
• Добавили новые достижения и подсказки в статистике.
• Ускорили запуск приложения.
• Исправили мелкие ошибки.
```

```
What's new

• Improved ad loading stability so the game never waits for a video.
• Added new achievements and stats hints.
• Faster app startup.
• Fixed minor bugs.
```

> Правила хорошего тона для notes: пишите только то, что реально изменилось, и на языке локализации.
> Не упоминайте «исправили рекламу» как «баг» — это звучит плохо для игрока, но полезно для
> прозрачности перед Play (важно для приложений с рекламой). Не более 500 символов.
